## 先分清你要的是哪一种“日本服务器”

中文里的“服务器租用”通常指独立服务器，也就是整台物理机归你一个人用；但搜这个词的人里有相当一部分实际需要的是云服务器或 VPS。这三类都属于“放在日本的服务器”，价格却相差一个数量级，混在一起比价得不到有用的结论。

- **独立服务器（裸金属）**：CPU、内存、磁盘、带宽全部独享，没有虚拟化层开销，性能可预测。东京、大阪机房的月付价大致在 75–638 美元之间。
- **云服务器**：基于 OpenStack/KVM 的虚拟化实例，分钟级开通，CPU、内存、磁盘、带宽可以单独扩容。日本节点的价格在几十到两三百元人民币一个月。
- **VPS**：在单机上切出的固定配额，配置写死，适合轻量站点、代理、测试环境。日本东京的入门款能做到 9 美元一个月。

一台 54 元/月的云服务器和一台 264 美元/月的独服不是同一件商品，把它们放进同一张比价表，只会得出“独服贵得离谱”这种没有意义的结论。先确认自己需要哪一类，再谈价格。

## 线路怎么选：CN2 GIA、SoftBank 还是国际 BGP

SoftBank 是日本本土大运营商，国际带宽充足，是日本独服最常见的默认线路。东京作为东北亚路由枢纽，直连 FASTER、PC-1、TPE 等海缆，对韩国、中国大陆、香港、新加坡和美西都有直接高速 peering。按服务商公开的口径，东京出口的典型延迟是：韩国低于 30ms、北京低于 50ms、香港低于 40ms、新加坡低于 80ms、美西低于 100ms。这些是服务商自己公布的数据，不同厂商的测量方式不一样，只能作为量级参考。

从中国大陆方向看，两个常见口径：云服务器厂商给出的数字是 30–70ms，独服厂商 FAQ 给出的数字是 50–80ms。两个数字并不矛盾，优化程度、测点位置和测试时间都会造成差异。

CN2 GIA 是中国大陆方向的直连优化线路，代价很直接：带宽被压到 20Mbps 这个量级，价格反而更高。Kirinhost 的 CN2 GIA 套餐是 20Mbps 配 1 个 IPv4，月付 180–230 美元；同价位的 SoftBank 套餐能给到 100Mbps 共享不限量。这条线路适合大陆访问占比高、并且业务本身不需要大带宽的场景，比如企业系统、数据库、跨境电商后台。如果站点有视频、下载、图片站这类流量型内容，20Mbps 会很快成为瓶颈。

市场上还有一类做法是把 CN2 和 SoftBank 做成 BGP 混合，按访问来源自动选路。听起来两边的好处都能占，实际体验取决于这家厂商自己的路由策略和带宽配比，选之前最好让销售给出具体的路由说明。

## 带宽的三种计价口径，不能按 Mbps 直接比价

这是日本独服报价里最容易看错的地方。同样写着“100Mbps”，可能是三种完全不同的东西。

## 独服还是云服务器，判断标准是什么

独服的价值在硬件完全独享，没有虚拟化层开销，性能稳定可预测。持续高 CPU 占用、大内存数据库、视频转码、高并发游戏后端，这些场景下独服的优势会体现出来。

云服务器胜在开通速度和弹性：华纳云那类产品购买即自动开通，CPU、内存、磁盘、带宽可以单独扩，1–2 分钟完成，还免备案。日 PV 几千的企业官网、展示型站点、小型电商、开发测试环境，云服务器完全够用，上独服属于把钱花在不需要的地方。

一个粗略的换算：一台 54 元/月的 1 核 1G 云服务器，和一台 120 美元/月的独服，价格差 15 倍以上。只有当你的业务确实吃满了一台独服的 CPU 和内存，这笔钱才花得值。

**滥用政策比想象中严。** Unihost 的条款写明，滥用投诉 12 小时内不处理、同类问题 3 次以上直接封号；允许 OpenVPN 和 torrent，禁止钓鱼、Warez、后门程序、破解站。做灰产类业务的，日本机房不是避风港。

**独服普遍是预付制。** Unihost 只做预付，最短 1 个月起，可选 3、6、9、12 个月，6 个月付给 2.5% 折扣、12 个月付给 5% 折扣。年付能省钱，但要先确认退款条款，中途不想用了，预付的钱大概率拿不回来。

**免备案是真的。** 日本机房不涉及 ICP 备案，买完就能上线，这也是很多人把业务放日本的首要原因。

**合规上有个加分项。** 日本《个人信息保护法》（APPI）对日本居民个人数据的跨境传输有严格要求，把数据放在日本境内可以简化合规流程。东京的机房普遍持有 ISO、ISAE、PCI-DSS、SOC 这几类认证（服务商公开口径），做面向日本用户的产品时，这点比几毫秒的延迟差异更值得考虑。

**IPMI/KVM 是独服的标配能力。** 它独立于操作系统运行，可以做远程开关机、重装系统、查看硬件状态。系统崩了进不去，也能通过它救回来。Unihost 还额外提供 BIOS 级访问和救援模式。选独服时，如果没有 IPMI/KVM，运维成本会高很多。

## 常见问题

**日本服务器需要备案吗？**
不需要。日本机房不适用中国大陆的 ICP 备案制度，购买后即可部署。这也是跨境电商和外贸站选日本机房的常见原因之一。

**东京和大阪怎么选？**
两地延迟差异对绝大多数业务可以忽略。东京的国际海缆接入更密集，做亚太枢纽更常见；大阪可以作为灾备或第二节点。如果厂商两个机房都提供，主节点放东京、备份放大阪是常见做法。

**IPMI 能做什么？**
远程电源控制、远程重装操作系统、查看硬件传感器状态。它的价值在于服务器系统崩溃、SSH 连不上时仍然可以操作，是独服区别于云服务器的一项实际能力。

**能装 Windows 吗？**
Kirinhost 和 SixCVM 的套餐都标明可选 Linux 或 Windows。Windows Server 的授权费用是否包含在报价里，需要单独确认，尤其是 Datacenter 版本。

**DDoS 防护是默认带的吗？**
Unihost 全部套餐含 DDoS 防护，流量经 VAC 清洗；SixCVM 机房内置流量清洗，可选高防 IP。清洗阈值和是否额外收费，各家不同，攻击风险高的业务要提前问清保额。

**续费会涨价吗？**
独服市场普遍按标价续费，不太玩首年低价那套，但预付折扣到期后月付价会回到原价。云服务器和 VPS 的促销价与续费价差异更常见，下单前把续费价单独确认一遍。
